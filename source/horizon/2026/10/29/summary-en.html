Apple's system git still trusts revoked eMudhra certificates ⭐️ 7.0/10

Apple's system-provided git and other macOS utilities continue to trust eMudhra certificates that have been revoked. Apple's official support article (support.apple.com/en-us/149555) provides a manual mitigation that requires editing the certificate chain, but macOS updates have reverted this fix at least once. Developers can avoid the issue by using Homebrew-installed git and curl instead of the system versions.

hackernews · galadran · Oct 28, 11:03 · Discussion

「Why it matters」 Any macOS developer relying on the system git or curl is exposed to potential MITM risk until the revoked CA certificates are removed. The immediate action is to run Apple's manual patch from support.apple.com/en-us/149555 or switch to Homebrew-provided git and curl, which do not depend on the compromised system trust store.

4B local LLM Mica v0.5 chains multiple-choice planning to craft netherite in Minecraft from bare hands ⭐️ 7.0/10

Reddit user /u/Top-Evidence174 demonstrates Mica v0.5, a 4B-parameter local LLM, breaking a natural-language Minecraft request ("get 3 porkchops and make a netherite ingot") into a chain of multiple-choice planning steps and executing it from bare hands. The pipeline asks sequential questions — how many items, category, subcategory, exact item from game data, recipient, quantity — with Mica selecting each answer and outputting probabilities shown in a side panel. A separate recipe planner lists valid actions; Mica picks the next step while a bot handles movement, mining, and crafting. The author notes Mica v0.5 4B is not a full visual agent and does not process continuous frames; decision times in the video are RTX 3090 estimates (author runs on AMD). The model weights are on Hugging Face (sky7350/Mica-v0.5-4B) and code on GitHub (akivet/Mica), but the complete Minecraft agent is not yet released. The author claims local decision models like Mica are ~10–60× faster than API-only alternatives (Jev, Clef, Ms Decision), enabling many more judgment calls per second.

「Why it matters」 If you build small-model agents, the chain-of-multiple-choice-questions pattern is a reproducible design you can implement today: decompose a fuzzy user request into a deterministic sequence of constrained choices sourced from your domain data (here, Minecraft's item/recipe registry), let a tiny local model pick each option with a confidence score, and feed the result to a classical planner/executor.
