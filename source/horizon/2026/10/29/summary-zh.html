4B 本地模型 Mica v0.5 用多选题链式规划在 Minecraft 中从零合成下界合金 ⭐️ 7.0/10

Reddit 用户 /u/Top-Evidence174 展示了一个 40 亿参数的本地 LLM —— Mica v0.5 —— 能把自然语言指令（"我饿了，帮我弄至少 3 个熟猪排和一个下界合金锭"）拆解为一连串小型多选题，再由模型逐步作答并给出概率，从而指挥机器人从空手开始完成采木、制工具、挖铁、钻石、合成黑曜石、进下界、挖远古残骸、合成金锭、最终合成下界合金锭的全过程。视频右侧面板实时显示每个决策的选项与概率。作者强调：这不是端到端视觉智能体，而是把「理解指令」拆成通用的判断链，模型只负责决策，游戏操作由现成 bot 执行。模型权重已上传 Hugging Face (sky7350/Mica-v0.5-4B)，代码库在 github.com/akivet/Mica，但完整 Minecraft 智能体尚未发布，作者表示「还没做完」。作者在 AMD GPU 上测试，决策耗时为 RTX 3090 估算值，并称同规模本地模型比纯 API 决策模型快 10–60 倍。

reddit · r/LocalLLaMA · /u/Top-Evidence174 · 10月28日 18:21

「实用价值」 对想自建轻量级本地智能体（尤其是 Minecraft 类任务规划）的开发者有参考价值：核心思路是把复杂指令拆解为可枚举的多选判断链，再由小模型逐步决策，代码只提供游戏数据生成的选项。可先克隆 GitHub 仓库或下载 HF 权重复现决策管线，或按作者描述让编码助手（如 Claude Code）按相同思路实现原型。完整智能体尚未开源，短期内无法直接拿来跑服务器。

标签: #local-llm, #agentic-ai, #minecraft, #task-planning, #small-language-models
