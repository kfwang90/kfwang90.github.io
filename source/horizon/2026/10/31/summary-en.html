Compromised Claude Code Extension on Cursor Marketplace Injects SSH Backdoor ⭐️ 7.0/10

A malicious actor published a tampered copy of the Claude Code VS Code extension on the Cursor marketplace (via Open VSX registry) that injected an attacker's SSH public key labeled 'svc-telemetry' into users' ~/.ssh/authorized_keys. The compromised extension was live from approximately 2:27 AM PT to 1:35 PM PT on Thursday, October 30, 2026. Anthropic confirmed they did not build or publish this extension and that official Anthropic distribution channels are unaffected. Detection commands: on macOS run `grep -qs svc-telemetry ~/.ssh/authorized_keys && echo "svc-telemetry key found" || echo "No key found; machine not impacted"`; on Windows run the equivalent PowerShell command to check for the key.

hackernews · _chall · Oct 30, 07:09 · Discussion

「Why It Matters」 Developers who installed the Claude Code extension from the Cursor marketplace during the compromise window should immediately run the detection commands and, if the malicious key is found, remove it from authorized_keys and rotate any potentially exposed credentials. This is a supply-chain attack limited to the Cursor/Open VSX distribution channel; users of Anthropic's official channels are not affected. First step: verify your installation source and run the detection command.
