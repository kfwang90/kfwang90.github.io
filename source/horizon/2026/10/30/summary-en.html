Unmanned Software Factories: Do We Need Complex Multi-Agent Orchestration? ⭐️ 8.0/10

Larry Liu (@xqliu) analyzes the paper "Instant Software Factories" which demonstrates that unmanned software factories can run without central orchestration — agents coordinate via GitHub Issues, PRs, and execution logs. The paper observed a 15× daily merge increase over 15–17 days, but crucially found 5.6% of "fixed" issues were actually incorrect. Liu argues traditional productivity metrics (PR count, issue closure rate) break down when agents self-create, self-review, and self-verify work. He proposes a three-layer measurement framework: Activity (tasks executed), Delivery (independently verified completions), and Outcome (user value). Liu's own product Orbi implements this pattern with built-in independent verification: separate coding/review sessions, mandatory review gates, counting only merged PRs as delivery, and separate release tasks. Orbi is open source at orbi-build/orbi.
