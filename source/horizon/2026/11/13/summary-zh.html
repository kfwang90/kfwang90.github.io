Rust 1.100 发布：never 类型、自定义分配器与 Cargo 新特性稳定 ⭐️ 9.0/10

Rust 1.100 于 2026-11-12 正式发布，已可通过 rustup 升级使用。本版本稳定了多项长期期待的语言与工具链特性：never 类型（!）与自定义全局分配器正式可用；Cargo 引入依赖冷却期（RFC 3923），可配置最小发布时间以忽略过新版本；cargo install 默认使用 .crate 包内的 lockfile，–locked 变为无操作；新增未使用依赖警告（默认 warn 级别）；标准库新增 bool::toggle、Box::map、str::trim_prefix/trim_suffix 与 Path::trim_prefix 等实用 API。所有特性均为已发布可用状态，非预告。

hackernews · mbStavola · 11月12日 18:39 · 社区讨论

「实用价值」 Rust 开发者可立即升级并在代码中使用 never 类型表达不可达分支、自定义分配器控制内存策略；在 Cargo.toml 中配置依赖冷却期可降低供应链风险；cargo install 行为简化减少锁文件冲突；未使用依赖警告帮助清理冗余依赖；新标准库 API 简化常见字符串、路径与布尔操作。建议第一步执行 rustup update stable 升级，随后在项目中逐项尝试相关特性。

标签: #Rust, #programming-languages, #tooling, #software-engineering, #release
