Rust 1.100 stabilizes never type, custom allocators, and Cargo dependency cooldowns ⭐️ 9.0/10

Rust 1.100 was released on 2026-11-12 and is available now via rustup. The release stabilizes the never type (!), custom allocators, and Cargo dependency cooldowns (RFC 3923) which let resolvers ignore recently published crate versions unless already locked. Cargo install now uses the lockfile inside .crate tarballs by default, making –locked a no-op, and Cargo warns about unused dependencies by default. New standard library APIs include bool::toggle(), Box::map(), str::trim_prefix/suffix(), and Path::trim_prefix().

「Why it matters」 Rust developers can immediately adopt the never type for exhaustive matching, plug in custom allocators for embedded or high-performance contexts, and enable dependency cooldowns to mitigate supply-chain risk. The Cargo improvements reduce lockfile friction and surface dead dependencies automatically. Upgrade with `rustup update stable` and test the new APIs in existing codebases.
