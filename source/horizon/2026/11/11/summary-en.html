Google Chrome releases modern-web-guidance v1.0 for coding agents ⭐️ 7.0/10

Google Chrome has released modern-web-guidance v1.0, an open-source knowledge base of 200+ curated guides developed with Firefox, MDN, and Edge. The package teaches coding agents to use native browser primitives — such as CSS.highlights, <dialog>, and field-sizing — instead of legacy JavaScript patterns. It installs via `npx modern-web-guidance@latest install` and includes a CLI for search and a deterministic legacy-scan trained on 30,000 GitHub repos (reported 92% precision). The authors claim agents improve from 55% to 92% pass rates on 200 frontend tasks when guided. Readable guides are published at developer.chrome.com/docs/modern-web-guidance/guides. Some listed features are Chrome-only and not yet supported in Firefox or Safari.
