### [Qwen3.5-9B runs on PS4 GPU at 31–39 tok/s via MTP speculative decoding](https://www.reddit.com/r/LocalLLaMA/comments/1xvbn2m/qwen359b_running_on_a_ps4s_gpu_offline_using_its/) ⭐️ 9.0/10

The open-source project garlic-llm runs Qwen3.5-9B on a stock PlayStation 4 GPU offline at 31–39 tokens per second. The model&\#x27;s built-in MTP head enables speculative decoding, drafting up to two tokens that the full model verifies in a single pass, raising throughput from 22 to 31–39 tok/s. Weights are packed into custom 4-bit and 3-bit formats to fit roughly 4.5 GiB. The code is free and open source on GitHub \(leonardo-alegria/garlic-llm\) and model weights are available on Hugging Face \(garlic-llm/garlic-llm-ps4\). No cloud, subscription, or Linux is required.

reddit · r/LocalLLaMA · /u/leonardo\_alegria · Nov 13, 16:00

**「Why it matters」** PS4 owners can now run a capable 9B-parameter LLM locally for chat, coding, and voice tasks without any external dependencies. The first step is to download the garlic-llm-ps4 weights from Hugging Face and follow the garlic-llm repository instructions to launch the model on the console&\#x27;s GPU.

### [datasette-leaflet 0.3 fixes OpenStreetMap referrer policy](https://simonwillison.net/2026/Nov/13/datasette-leaflet/) ⭐️ 6.0/10

datasette-leaflet 0.3 addresses a referrer-policy violation when loading OpenStreetMap tiles in Datasette mapping plugins. The plugin previously relied on Datasette&\#x27;s \`Referrer-Policy: no-referrer\` header, which conflicted with OSM&\#x27;s tile usage policy requiring a referrer header. Version 0.3 sets the tile request referrer policy to \`strict-origin-when-cross-origin\`, sending the host but not the full page path. The release is available on GitHub.

rss · Simon Willison · Nov 13, 22:30

**「Why It Matters」** Datasette users with Leaflet-based mapping plugins should upgrade to 0.3 to comply with OpenStreetMap&\#x27;s tile usage policy and avoid potential tile loading issues. First step: update the datasette-leaflet dependency in your Datasette project.

**Tags**: `#datasette`, `#leaflet`, `#openstreetmap`, `#plugin`, `#referrer-policy`
