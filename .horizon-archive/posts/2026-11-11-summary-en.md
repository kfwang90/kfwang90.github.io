### [Google Chrome releases modern-web-guidance v1.0 for coding agents](https://github.com/GoogleChrome/modern-web-guidance) ⭐️ 7.0/10

Google Chrome has released modern-web-guidance v1.0, an open-source knowledge base of 200+ curated guides developed with Firefox, MDN, and Edge. The package teaches coding agents to use native browser primitives — such as CSS.highlights, &lt;dialog&gt;, and field-sizing — instead of legacy JavaScript patterns. It installs via \`npx modern-web-guidance@latest install\` and includes a CLI for search and a deterministic legacy-scan trained on 30,000 GitHub repos \(reported 92% precision\). The authors claim agents improve from 55% to 92% pass rates on 200 frontend tasks when guided. Readable guides are published at developer.chrome.com/docs/modern-web-guidance/guides. Some listed features are Chrome-only and not yet supported in Firefox or Safari.

hackernews · paulirish · Nov 10, 18:01 · [Discussion](https://news.ycombinator.com/item?id=50443812)

**「Why it matters」** Front-end developers using coding agents \(Cursor, Copilot, Claude Code, etc.\) can immediately add this skill to steer agents toward dependency-free, standards-based solutions. First step: run \`DISABLE\_TELEMETRY=1 npx modern-web-guidance@latest install\` in a project, then try \`legacy-scan ./src\` to surface outdated patterns the agent can modernize. Teams should verify cross-browser support for any suggested feature before shipping.
